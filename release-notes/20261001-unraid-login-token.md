The login screen now supports the default `torrentng` / `torrentng` credentials on local installs, as well as the configured API token in either the username or password field. API tokens remain available for automation. The Unraid template points to its API Token setting, and Settings -> Security lets an authenticated admin change or restore WebUI credentials.
